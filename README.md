# Lumenfall

빛이 드는 스테인드글라스 그림 창을 완성하는 캐주얼 논리 퍼즐.

물감을 유리 조각에 떨어뜨리면 이웃한 조각까지 번지고, 번짐이 겹친 자리에서는 색이 섞인다.
굵은 납선은 번짐을 막는다. 목표 그림과 똑같이 만들면 창 뒤에서 빛이 들어오고, 완성한 창은 창고에 걸린다.

**플레이:** https://fifa3827-lgtm.github.io/lumenfall/

## 조작

| 동작 | 결과 |
|---|---|
| 아래 물감 방울을 톡 | 쓸 물감 고르기 |
| 유리 조각을 톡 | 물감 떨어뜨리기 |
| 되돌리기 | 마지막 방울 취소 |

## 규칙

- 물감은 빨강 · 노랑 · 파랑 세 가지.
- 「옆까지」는 이웃 한 겹, 「두 칸」은 두 겹까지 번진다. 굵은 납선은 넘지 못한다.
- 서로 다른 두 원색이 만나면 주황 · 초록 · 보라가 된다. 같은 색은 여러 번 부어도 그대로다.
- 세 원색이 한 조각에 모두 모이면 탁해진다.
- 흐리게 보이는 부분은 이미 끼워진 유리라 칠하지 않는다.
- 같은 고리가 달린 두 조각은 쌍둥이다. 한쪽에 물감이 닿으면 짝에도 닿는다(9단계부터).
- 빗금 유리는 처음 닿은 색으로 굳는다. 떨어뜨리는 순서가 중요해진다(15단계부터).
- 투명 유리에는 물감이 묻지 않고 번짐만 지나간다(21단계부터).
- ✦가 달린 빛 방울은 닿은 조각에서 그 색을 뺀다. 주황에 빛 노랑을 떨어뜨리면 빨강이 된다(27단계부터).
- 완성하면 별 하나. 되돌리기 없이 하면 하나, 기준 수 이하로 하면 또 하나.
  5단계부터는 필요 없는 방울이 섞여 있다.

## 그림

튤립 · 물고기 · 집 · 나무 · 버섯 · 나비 · 돛단배 · 아이스크림 · 로켓 · 하트 풍선 · 별 · 해님 ·
눈사람 · 단풍잎 · 수박 · 우산 · 연필 · 종 · 책 · 고양이 얼굴 · 부엉이 · 거북 · 선인장 · 컵케이크 · 열기구 · 달팽이

스물여섯 가지를 차례로 돌고, 다시 나올 때는 다른 색 조합과 더 잘게 나뉜 조각으로 나온다.

## 단계

1단계는 반짝이는 고리로 첫 방울 자리를 알려 준다. 1·2단계는 한 부분만 칠하고,
단계가 오를수록 칠할 부분·조각 수·필요 없는 방울이 늘고 특수 유리가 나온다.
같은 단계는 언제나 같은 판이 나온다. 네 판마다 배경이 아침 · 한낮 · 저녁 · 밤으로 바뀐다.

완성한 그림은 창고의 여섯 묶음(정원 · 하늘과 바다 · 집과 학교 · 맛있는 것 · 동물 친구 · 계절) 벽에 걸린다.

창턱의 고양이는 판이 열리면 궁금해하고, 탁해지면 놀라고, 완성하면 기뻐한다.

## 파일

```
index.html         화면과 스타일
assets.js          에셋 경로
pictures.js        그림 창 도안 (tools/pic/build.py로 만든다)
game.js            게임 로직 · 생성기 · 렌더링 · 효과 · 소리
geo.js             예전 무늬 창 모양 (지금은 쓰지 않음)
assets/            유리 텍스처 7장, 소리 4개
assets/char/       고양이 5장, 물감 방울 12장
tools/pic/         도안(designs.py)과 조각 자르기(build.py), 시험판 한 장짜리 HTML 만들기(artifact.py)
docs/design.md     규칙과 생성기 설계
docs/assets.md     에셋 제작 방법과 출처
```

## 실행

정적 파일이라 그대로 웹 서버에 올리면 된다. 로컬에서는

```
python3 -m http.server 8000
```

소리는 브라우저 정책상 화면을 한 번 누른 뒤부터 난다.
