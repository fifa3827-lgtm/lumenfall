# Lumenfall

빛이 드는 스테인드글라스 그림 창을 완성하는 캐주얼 논리 퍼즐.

물감을 유리 조각에 떨어뜨리면 이웃한 조각까지 번지고, 번짐이 겹친 자리에서는 색이 섞인다.
굵은 납선은 번짐을 막는다. 목표 그림과 똑같이 만들면 창 뒤에서 빛이 들어오고, 완성한 창은 창고에 걸린다.

**플레이:** https://fifa3827-lgtm.github.io/lumenfall/

## 조작

| 동작 | 결과 |
|---|---|
| 아래 물감 방울을 톡 | 쓸 물감 고르기 |
| 유리 조각을 톡 | 물감 떨어뜨리기 |
| 되돌리기 | 마지막 방울 취소 |
| 목표 그림을 톡 | 목표를 창 크기로 크게 보기 (다시 누르면 돌아옴) |
| 「단계」 또는 창 이름을 톡 | 깬 단계를 골라 다시 하기 (별 세 개 도전) |
| 「창고」 | 모은 그림 보기, 창턱 장식 올리고 내리기 |

## 규칙

- 물감은 빨강 · 노랑 · 파랑 세 가지.
- 「옆까지」는 이웃 한 겹, 「두 칸」은 두 겹까지 번진다. 굵은 납선은 넘지 못한다.
- 서로 다른 두 원색이 만나면 주황 · 초록 · 보라가 된다. 같은 색은 여러 번 부어도 그대로다.
- 세 원색이 한 조각에 모두 모이면 탁해진다.
- 흐리게 보이는 부분은 이미 끼워진 유리라 칠하지 않는다.
- 섞인 색 조각 가운데의 작은 점 두 개는 그 조각에 든 원색이다. 주황이면 빨강·노랑.
- 같은 고리가 달린 두 조각은 쌍둥이다. 한쪽에 물감이 닿으면 짝에도 닿는다(11단계부터).
- 빗금 유리는 처음 닿은 색으로 굳는다. 떨어뜨리는 순서가 중요해진다(18단계부터).
- 투명 유리에는 물감이 묻지 않고 번짐만 지나간다(24단계부터).
- ✦가 달린 빛 방울은 닿은 조각에서 그 색을 뺀다. 주황에 빛 노랑을 떨어뜨리면 빨강이 된다(30단계부터).
- 완성하면 별 하나. 되돌리기 없이 하면 하나, 기준 수 이하로 하면 또 하나.
  8단계부터는 필요 없는 방울이 섞여 있다.

일흔두 가지를 차례로 돌고, 다시 나올 때는 다른 색 조합으로 나온다.

## 단계

1단계는 반짝이는 고리로 첫 방울 자리를 알려 준다. 1~3단계는 한 부분만 칠하고,
단계가 오를수록 칠할 부분·조각 수·필요 없는 방울이 늘고 특수 유리가 나온다.
같은 단계는 언제나 같은 판이 나온다. 네 판마다 배경이 아침 · 한낮 · 저녁 · 밤으로 바뀐다.

창턱의 고양이는 판이 열리면 궁금해하고, 탁해지면 놀라고, 완성하면 기뻐한다.

## 마을

창고 맨 위의 밤 마을. 창고 묶음 하나마다 건물 하나가 있고, 그 묶음에서 모은 그림만큼 창에 불이 들어온다.
묶음을 다 모으면 건물 전체가 환해진다(등대는 빛을 비추고, 학교 깃발이 펄럭인다).

온실(정원) · 학교(집과 학교) · 성당(축제와 계절) · 기차역(탈것) · 천문대(하늘과 우주) · 헛간(동물 친구) · 빵집(맛있는 것) · 과일 가게(과일과 채소) · 등대(바다)

## 창턱 꾸미기

별을 모으면 창 아래 창턱에 올릴 장식이 생긴다. 한 번에 넷까지 올릴 수 있다.

새싹 화분(별 3) · 촛불(8) · 조개껍데기(14) · 찻잔(21) · 책 더미(29) · 어항(38) · 모래시계(48) · 선인장 화분(58) · 지구본(70) · 등불(84) · 별 병(100) · 유리 등(120) ·
스노볼(140) · 호박 등불(160) · 풍차(180) · 종이배(200) · 꽃병(220) · 기차 모형(245)

별은 단계마다 가장 많이 받은 수를 더한다. 이미 깬 단계를 다시 해서 별을 올려도 늘어난다.

## 파일

```
index.html         화면과 스타일
assets.js          에셋 경로
pictures.js        그림 창 도안 (tools/pic/build.py로 만든다)
deco.js            창턱 장식 그림 18가지
village.js         마을 지도(건물 9채)
game.js            게임 로직 · 생성기 · 렌더링 · 효과 · 소리
geo.js             예전 무늬 창 모양 (지금은 쓰지 않음)
assets/            유리 텍스처 7장, 소리 4개
assets/char/       고양이 5장, 물감 방울 12장
tools/pic/         도안(designs.py)과 조각 자르기(build.py), 시험판 한 장짜리 HTML 만들기(artifact.py)
docs/design.md     규칙과 생성기 설계
docs/assets.md     에셋 제작 방법과 출처
```

## 실행

정적 파일이라 그대로 웹 서버에 올리면 된다. 로컬에서는

```
python3 -m http.server 8000
```

소리는 브라우저 정책상 화면을 한 번 누른 뒤부터 난다.
