# Lumenfall

빛이 드는 스테인드글라스 창을 완성하는 캐주얼 논리 퍼즐.

물감을 유리 조각에 떨어뜨리면 이웃한 조각까지 번진다.
번짐이 겹친 자리에서는 색이 섞인다. 빨강+노랑은 주황, 노랑+파랑은 초록,
파랑+빨강은 보라. 세 원색이 한 조각에 모두 모이면 탁해진다.

목표 그림과 똑같이 만들면 창 뒤에서 빛이 들어오고, 완성한 창은 창고에 남는다.

## 규칙

| 요소 | 설명 |
|---|---|
| 물감 | 빨강 · 노랑 · 파랑 세 가지 |
| 번짐 범위 | 「옆까지」는 이웃 한 겹, 「두 칸」은 두 겹 |
| 섞임 | 같은 색은 여러 번 부어도 그대로. 서로 다른 두 원색이 만나면 혼합색 |
| 탁함 | 세 원색이 한 조각에 모이면 실패 |

## 창 모양

장미창 · 벌집창 · 마름모창 · 별격자창 · 첨두창 · 삼각창 · 십자창 · 팔엽창 · 쌍아치창

두 판마다 모양이 바뀐다. 조각을 다각형으로 정의하고 맞닿은 변을 찾아
이웃을 계산하므로, 새 모양을 추가해도 규칙은 그대로 작동한다.

## 단계

1~8단계는 손으로 만든 도입부로, 규칙을 하나씩 익힌다.
9단계부터는 생성기가 만든다. 무작위로 500개를 만들어 대칭성·색 다양성·
혼합 비율·채움 정도로 점수를 매기고 가장 높은 것을 고른다.
단계 번호가 난수 씨앗이므로 같은 단계는 언제나 같은 판이 나온다.

## 파일

```
index.html    화면과 스타일
assets.js     에셋 경로
geo.js        창 모양 정의와 이웃 계산
game.js       게임 로직 · 생성기 · 렌더링 · 소리
assets/       유리 텍스처 7장, 소리 4개
```

## 실행

정적 파일이라 웹 서버에 올리거나 로컬에서 열면 된다.
소리는 브라우저 정책상 화면을 한 번 누른 뒤부터 재생된다.

```
python3 -m http.server 8000
```
