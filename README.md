# Lumenfall

빛이 드는 스테인드글라스 창을 완성하는 캐주얼 논리 퍼즐.

물감을 유리 조각에 떨어뜨리면 이웃한 조각까지 번지고, 번짐이 겹친 자리에서는 색이 섞인다.
목표 그림과 똑같이 만들면 창 뒤에서 빛이 들어오고, 완성한 창은 창고에 걸린다.

**플레이:** https://fifa3827-lgtm.github.io/lumenfall/

## 조작

| 동작 | 결과 |
|---|---|
| 아래 물감 방울을 톡 | 쓸 물감 고르기 |
| 유리 조각을 톡 | 물감 떨어뜨리기 |
| 금색 눈금이 있는 고리를 빙 끌기 | 고리를 돌려 색을 옮기기 |
| 되돌리기 | 마지막 방울이나 돌리기 취소 |

## 규칙

- 물감은 빨강 · 노랑 · 파랑 세 가지.
- 「옆까지」는 이웃 한 겹, 「두 칸」은 두 겹까지 번진다.
- 서로 다른 두 원색이 만나면 주황 · 초록 · 보라가 된다. 같은 색은 여러 번 부어도 그대로다.
- 세 원색이 한 조각에 모두 모이면 탁해진다.
- 장미창과 팔엽창은 고리를 돌릴 수 있다. 번짐은 조각 위치를 따르므로,
  칠하고 돌리는지 돌리고 칠하는지에 따라 결과가 달라진다.

## 창 모양

장미창 · 벌집창 · 마름모창 · 별격자창 · 첨두창 · 삼각창 · 십자창 · 팔엽창 · 쌍아치창

## 단계

1~10단계는 손으로 만든 도입부다. 번짐, 섞임, 고리 돌리기를 하나씩 익힌다.
11단계부터는 생성기가 만든다. 같은 단계는 언제나 같은 판이 나온다.
네 판마다 배경이 아침 · 한낮 · 저녁 · 밤으로 바뀐다.

## 파일

```
index.html      화면과 스타일
assets.js       에셋 경로
geo.js          창 모양 정의와 이웃 계산
game.js         게임 로직 · 생성기 · 렌더링 · 효과 · 소리
assets/         유리 텍스처 7장, 소리 4개
docs/design.md  규칙과 생성기 설계
docs/assets.md  에셋 제작 방법과 출처
```

## 실행

정적 파일이라 그대로 웹 서버에 올리면 된다. 로컬에서는

```
python3 -m http.server 8000
```

소리는 브라우저 정책상 화면을 한 번 누른 뒤부터 난다.
